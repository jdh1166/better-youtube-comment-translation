# Better YouTube Comment Translation

[English](README.md) · **한국어**

유튜브 댓글과 답글 **전부**를 번역하는 크롬 확장 프로그램. 유튜브가 번역 버튼을 띄워주는 것만이 아니라.

## 왜 만들었나

유튜브에도 댓글 번역 기능은 있습니다. 다만 뜰 때도 있고 안 뜰 때도 있습니다.

실제 DOM을 뜯어보면 이유가 보입니다. 유튜브는 **모든** 댓글에 번역 버튼을 미리 심어두고,
어떤 댓글에 그걸 보여줄지 **서버가 댓글마다 개별적으로** 결정합니다:

```html
<ytd-tri-state-button-view-model class="translate-button" state="untoggled" hidden="">
```

`hidden` 이 붙으면 버튼이 사라집니다. 확인해본 영상에서는 한국어 설정 페이지에 로드된 댓글 20개가
전부 영어였는데도 **20개 전부 버튼이 숨겨져** 있었습니다. 짧은 댓글, 답글, 이모지가 섞인 댓글에서
특히 자주 누락됩니다.

이 확장은 그 판단을 내 브라우저가 직접 합니다.

## 기능

|                  | 유튜브 기본             | 이 확장                              |
| ---------------- | ----------------------- | ------------------------------------ |
| 번역 버튼 노출   | 서버가 임의로 결정      | 번역이 필요한 모든 댓글              |
| 답글             | 자주 누락               | 항상 지원                            |
| 일괄 번역        | 없음 (하나씩 클릭)      | 스크롤하며 자동 번역                 |
| 원문 확인        | 토글하면 번역문이 사라짐 | 원문 + 번역문 병기                   |
| 번역 엔진        | 선택 불가               | Chrome 내장 / DeepL / Google / LLM   |
| 캐시             | 없음                    | 같은 댓글을 다시 번역하지 않음       |

그 밖에:

- **언어 자동 감지** — Chrome `LanguageDetector` API. 모델을 못 쓰는 환경에서는 문자 스크립트와
  불용어 기반 추정으로 대신합니다.
- **이미 내 언어인 댓글은 건너뜀** — 버튼조차 만들지 않아 화면이 깔끔합니다.
- **원문을 건드리지 않음** — 번역문을 형제 노드로 추가하기 때문에 커스텀 이모지, `@멘션`, 링크,
  타임스탬프가 그대로 남습니다.
- **영어 경유 번역** — 내장 엔진이 직접 지원하지 않는 언어쌍은 `원문 → 영어 → 목표어` 2단계로 처리합니다.
- **요청 배치 처리** — 원격 엔진은 180ms 동안 모인 댓글을 한 번의 API 호출로 묶어 보냅니다.
- **유튜브 테마 자동 대응** — OS 설정과 무관하게 유튜브 테마를 런타임에 판정합니다.

## 설치

아직 크롬 웹스토어에 없습니다. 압축해제 상태로 로드하세요:

1. 이 저장소를 클론하거나 ZIP으로 내려받습니다.
2. 주소창에 `chrome://extensions` 를 입력합니다.
3. 우측 상단 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드**를 눌러 이 폴더를 선택합니다.
5. 이미 열려 있던 유튜브 탭은 **새로고침**합니다.

**요구 사항:** Chrome 138 이상, 데스크톱. 내장 Translator API가 데스크톱 전용입니다.
그보다 낮은 버전이거나 언어팩을 못 쓰는 환경이라면 아래의 대체 엔진을 설정하세요.

## 사용법

### 댓글 하나 번역하기

번역이 필요한 댓글마다 **번역** 버튼과 감지된 원문 언어가 함께 표시됩니다. 누르면 원문 아래에
번역문이 붙습니다.

버튼을 다시 누르면(이때는 **원문만**) 번역문이 접힙니다.

어떤 언어를 처음 번역할 때는 크롬이 해당 언어팩을 내려받아야 합니다. 이때 버튼이
**`<언어>` 번역 켜기** 로 바뀌는데, 한 번만 눌러주면 그 뒤로는 같은 언어 댓글이 자동으로 번역됩니다.
이 클릭은 이 확장이 아니라 **크롬의 요구사항**입니다 — 브라우저는 사용자 제스처 없이 모델 다운로드를
시작하지 않습니다.

### 전부 번역하기

툴바 아이콘을 눌러 팝업을 열고 **자동 번역**을 켜면, 스크롤하면서 화면에 들어온 댓글이 답글까지
자동으로 번역됩니다.

지금 화면에 있는 것만 한 번에 처리하려면 **지금 보이는 댓글 번역**을 누르거나
<kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> 를 누르세요.

### 단축키

| 단축키 | 동작 |
| ------ | ---- |
| <kbd>Alt</kbd>+<kbd>T</kbd> | 자동 번역 켜기/끄기 |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> | 현재 보이는 댓글 모두 번역 |

`chrome://extensions/shortcuts` 에서 바꿀 수 있습니다.

### 설정

자주 쓰는 것은 팝업에 있고, **전체 설정**을 누르면 옵션 페이지가 열립니다:

| 설정 | 기본값 | 설명 |
| ---- | ------ | ---- |
| 확장 프로그램 사용 | 켜짐 | 전체 on/off |
| 자동 번역 | 꺼짐 | 스크롤하며 자동 번역 |
| 번역할 언어 | 한국어 | 32개 언어 |
| 답글도 번역 | 켜짐 | 유튜브가 가장 자주 놓치는 부분 |
| 이미 같은 언어면 건너뛰기 | 켜짐 | 읽을 수 있는 댓글에는 버튼을 안 만듦 |
| 원문 함께 보기 | 켜짐 | 끄면 번역문만 남기고 원문을 숨김 |
| 언어·엔진 배지 표시 | 켜짐 | 번역문 위에 `English → 한국어 · Chrome` 표시 |
| 유튜브 기본 번역 버튼 숨기기 | 켜짐 | 버튼이 두 개 겹치는 걸 방지 |
| 최소 글자 수 | 2 | 이보다 짧은 댓글은 무시 |
| 동시 번역 수 | 3 | 높이면 빠르지만 부하가 커짐 |
| 언어팩 자동 다운로드 | 꺼짐 | 최초 클릭을 생략하는 대신 백그라운드 다운로드 발생 |

## 번역 엔진

### Chrome 내장 (기본값, 권장)

API 키가 필요 없고 무료이며, **댓글 내용이 기기 밖으로 나가지 않습니다.** 크롬의 온디바이스
모델이 처리합니다. 언어쌍마다 최초 1회 모델을 내려받습니다.

### DeepL / Google Cloud Translation / LLM (선택)

옵션 화면에서 본인의 API 키를 넣고 **권한 허용**을 누르면 됩니다.

확장이 기본으로 요구하는 권한은 `youtube.com` 뿐입니다. 원격 엔진의 API 주소는 그 엔진을 실제로
켤 때 `chrome.permissions.request()` 로 개별 요청합니다.

LLM 엔진은 OpenAI 호환 `chat/completions` 엔드포인트면 무엇이든 씁니다. 슬랭·밈·말장난 번역이 가장
자연스럽지만 느리고 비용이 발생하며, **댓글이 해당 제공자에게 전송됩니다.**

**대체 엔진**을 지정해두면 기본 엔진이 실패하거나 해당 언어쌍을 지원하지 않을 때 자동으로 넘어갑니다.

## 개인정보

개발자에게 전송되는 데이터는 **일절 없습니다.** 개발자가 운영하는 서버 자체가 없고, 분석 도구나
추적기도 없습니다. 기본 엔진을 쓰면 아무것도 기기를 벗어나지 않습니다.

엔진별로 무엇이 전송되는지는 [PRIVACY.md](PRIVACY.md) 에 정리되어 있습니다.

## 개발

빌드 단계가 없습니다. 클론해서 폴더를 로드하면 끝입니다.

```
manifest.json              MV3
src/
  core/                    content script 와 service worker 가 공유
    constants.js           네임스페이스, 기본 설정, 엔진 메타데이터, 번역 제외 규칙
    util.js                해시, 타임아웃, 언어코드 정규화, 재시도
    settings.js            chrome.storage.sync 래퍼 + 변경 구독
    langdetect.js          LanguageDetector API + 휴리스틱 폴백
    cache.js               메모리 LRU + storage.local 영속화
    queue.js               동시 실행 제한, 중복 제거, 우선순위
    engine-builtin.js      Chrome Translator API (영어 경유 라우팅 포함)
  content/
    ytdom.js               유튜브 DOM 어댑터 (셀렉터 폴백, 테마 판정)
    ui.js                  댓글별 UI 렌더링
    content.js             오케스트레이터
    styles.css
  bg/
    service-worker.js      DeepL/Google/LLM 호출, 요청 검증, 단축키 라우팅
  ui/
    popup.*                빠른 설정
    options.*              전체 설정
test/
  harness.html             실제 유튜브 댓글 DOM 재현, 브라우저 검사 41건
  node-tests.js            헤드리스 검사 34건
```

### 설계 메모

- **번들러 없음.** `manifest.json` 의 순서대로 로드되어 `globalThis.BYCT` 하나를 공유합니다.
  서비스 워커는 같은 파일을 `importScripts()` 로 재사용합니다.
- **API 키는 content script 에 가지 않습니다.** 원격 번역은 전부 서비스 워커가 호출하고,
  content script 는 `BYCT.stripSecrets` 로 키 값을 아예 넘겨받지 않습니다.
- **서비스 워커는 content script 를 믿지 않습니다.** content script 는 결국 웹 페이지 안에서 도는
  코드이므로, 엔진 이름·항목 수·길이·언어 코드 형식을 검사한 뒤에만 외부 API 로 보냅니다.
- **댓글은 신뢰할 수 없는 입력입니다.** 텍스트 판정 경로를 전부 입력 길이에 선형으로 유지합니다 —
  중첩 수량자 정규식 하나가 실제 DoS 였습니다([CHANGELOG.md](CHANGELOG.md) 참고). LLM 엔진에는
  댓글 안의 지시문을 따르지 말라고 명시했고, 번역 결과는 항상 `textContent` 로만 넣습니다.
- **셀렉터 폴백.** 유튜브가 마크업을 자주 바꾸므로 모든 셀렉터에 후보를 여러 개 둡니다.
- **노드 재활용.** 유튜브(Polymer)는 스크롤 중 댓글 DOM 노드를 재사용합니다. 마킹만 믿으면 A 댓글
  번역이 B 댓글에 남으므로, 스캔할 때마다 저장된 원문과 현재 텍스트를 비교합니다.
- **테마는 유튜브 CSS 변수에 의존하지 않습니다.** 처음에는 `--yt-spec-text-primary` 를 썼는데
  유튜브가 그 체계를 `--yt-sys-color-*` 로 바꾸면서 모든 `var()` 가 조용히 폴백값으로 떨어졌고,
  다크 모드에서 번역문이 거의 검정으로 찍혔습니다. 지금은 `<html dark>` 속성을 1순위로,
  배경색 휘도를 2순위로 런타임 판정합니다.
- **모든 곳에 타임아웃.** 크롬의 `availability()` 가 영영 응답하지 않는 경우가 있고, `create()` 가
  진행 이벤트 없이 멈추는 경우도 있습니다. 둘 다 막아서 UI 가 무한 스피너에 갇히지 않게 합니다.

### 테스트

헤드리스:

```bash
node test/node-tests.js
```

34건 — 번역 제외 판정, ReDoS 회귀, 언어 코드 정규화, 서비스 워커 요청 검증.

DOM 이 필요한 것:

```bash
python -m http.server 8731 -d .
```

- `http://localhost:8731/test/harness.html` → **자동 검증 실행** 버튼 — 41건
- `python test/make-preview.py` 실행 후 `test/_preview/options.html` 로 확장 밖에서 UI 확인

하네스는 실제 유튜브 댓글 DOM 구조를 재현하고 `chrome.*` 를 인메모리 목으로 대체해서, 설치 없이
content script 로직을 검증합니다. 유튜브 CSS 변수는 **일부러 정의하지 않습니다** — 예전에 정의해뒀다가
위에 적은 다크 모드 버그를 가려버린 적이 있습니다.

## AI 사용 고지

이 확장은 **Claude (Anthropic Claude Code)** 와 함께 만들었습니다. DOM 조사, 아키텍처 설계, 구현,
테스트, 문서가 모두 AI 지원으로 작성되었습니다.

이걸 밝히는 이유는, 코드를 어떻게 평가해야 하는지와 직결되기 때문입니다:

- 동작은 자동 검사 75건(헤드리스 34, 브라우저 41)으로 덮여 있고, DOM 관련 가정은 추측이 아니라
  실제 youtube.com 에서 확인했습니다.
- 보안·성능 점검 과정에서 실제 ReDoS 취약점 하나, API 키 노출 경로 하나, 그리고 여러 정확성 버그를
  찾아 고쳤습니다. 각각의 측정값과 함께 [CHANGELOG.md](CHANGELOG.md) 에 기록되어 있습니다.
- 제3자 감사는 받지 않았습니다. API 키를 맡기기 전에 소스를 직접 읽어보세요 — 다른 확장 프로그램도
  마찬가지겠지만요.
