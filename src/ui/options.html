Better YouTube Comment Translation

유튜브 댓글과 답글 전체를 원하는 언어로 번역합니다.

설치가 완료되었습니다. 기본 설정은 Chrome 내장 번역(온디바이스)이라 API 키 없이 바로 쓸 수 있습니다. 유튜브 영상에서 댓글의 번역 버튼을 누르면 최초 1회 언어팩을 내려받습니다.

확인 중…

Chrome 138 이상 데스크톱에서만 동작합니다. 번역은 전부 기기 안에서 이뤄지며 댓글 내용이 외부로 전송되지 않습니다. 언어쌍마다 최초 1회 모델을 내려받습니다. 직접 지원하지 않는 언어쌍은 영어를 경유해 2단계로 번역합니다.

원문 언어를 알아내는 데 쓰는 모델입니다. 준비되지 않으면 문자·불용어 기반 추정으로 대신 동작하는데, 짧은 라틴 문자 댓글에서 가끔 틀립니다.

무료 키는 :fx로 끝납니다. 키 발급받기

Google Cloud 콘솔에서 Cloud Translation API를 활성화한 프로젝트의 키가 필요합니다.

슬랭·밈·말장난 번역이 가장 자연스럽지만 느리고 비용이 발생합니다. 댓글이 API 제공자에게 전송된다는 점을 유의하세요.
